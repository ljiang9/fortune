# fortune

终端随机格言：每天一句，离线可读。纯标准库，零依赖。

## 安装

无需安装，把目录放到 `PATH` 里或直接用模块方式运行：

```bash
python3 -m fortune
```

## 用法

```bash
fortune                  # 随机抽一条
fortune -c 中文          # 只看中文格言
fortune -c en            # 只看英文格言
fortune --list-categories
fortune --json           # JSON 输出，方便脚本调用
fortune --seed 42        # 固定种子，结果可复现（演示/测试用）
```

输出示例：

```
  “千里之行，始于足下。”
  —— 《道德经》
```

## 格言库

内置 60 条，全部为公有领域内容，人工精选并注明出处：

- **中文**（30 条）：先秦典籍（《论语》《道德经》《孟子》《荀子》）、
  唐宋诗词（李白、杜甫、陆游等）、传统谚语。
- **en**（30 条）：斯多葛学派（奥勒留、塞涅卡、爱比克泰德）、
  莎士比亚、富兰克林、爱迪生等已故超过百年的作者，
  另有佛经（《法句经》）传统译文的自我转述。

## 设计取舍

- 默认用 `random.SystemRandom`（系统熵），每次都不一样；
  `--seed` 切到确定性 PRNG，仅用于演示和测试。
- 不做网络请求、不读外部文件，开箱即用。

## 已知局限

- 精选库只有 60 条，不是格言数据库；看多了会重复——这是"小巧"的代价。
- 英文引文采用流传最广的英文表述，个别归属存在争议的已按通行说法标注。
- 想加自己的格言？直接改 `fortune.py` 里的 `QUOTES` 列表即可。
